# 🎮 Jogos no Navegador

Site de jogos simples feitos em HTML, CSS e JavaScript puro, sem instalação e sem servidor.

**Jogar:** https://raphaellvs32-boop.github.io/jogos/

## Jogos

| Jogo | Pasta | Controles |
|------|-------|-----------|
| Snake | `jogos/snake/` | Setas, WASD, botões na tela ou deslizar o dedo |
| Jogo da Memória | `jogos/memoria/` | Clique ou toque nas cartas |
| 2048 | `jogos/2048/` | Setas, WASD ou deslizar o dedo |

Os recordes ficam salvos no próprio navegador (localStorage).

## Como adicionar um jogo novo

1. Criar a pasta `jogos/nome-do-jogo/` com um `index.html`.
2. Usar `../../style.css` para manter o visual padrão.
3. Adicionar um card em `index.html` (página inicial) apontando para a pasta.
